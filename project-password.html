Project Overview

This project is an Ethical Password Cracking Simulator built with vanilla JavaScript to demonstrate how weak passwords are vulnerable to common attack techniques. The simulator is strictly educational and designed to promote secure password practices.

Objective

The goal of this simulator is to help users understand:

  • How dictionary attacks exploit commonly used passwords
  • Why short passwords are vulnerable to brute-force attacks
  • The importance of strong, complex password creation

How the Simulator Works

  1. The user enters a password into an input field
  2. The system performs a dictionary attack using a predefined list of common passwords
  3. If the dictionary attack fails, a brute-force feasibility check is simulated based on password length
  4. Results are displayed in real time to explain the outcome

Security Concepts Demonstrated

  • Dictionary-based password cracking
  • Brute-force attack feasibility
  • Password entropy and length considerations
  • Ethical hacking principles

Technologies Used

  • HTML5
  • CSS3
  • JavaScript (ES6)

Ethical Notice

This simulator does not perform real password cracking. It is intended solely for educational purposes to promote cybersecurity awareness and ethical security testing.
